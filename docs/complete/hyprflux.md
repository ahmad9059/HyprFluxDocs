# Install HyprFlux on Existing Arch

This route exists so older links keep working. The maintained procedure is the [existing Arch installation guide](/general/installation).

The installer performs full provisioning, not a configuration-only copy. It updates Arch Linux, installs the desktop package set and services, deploys the HyprFlux configuration, and offers a reboot when it finishes.

If Arch Linux is not installed yet, choose either the [HyprFlux ISO](/general/iso-installation) or prepare a supported base with the [Arch Linux guide](/complete/arch) first.
