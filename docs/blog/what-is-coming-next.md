# What Is Coming Next

_Published: March 13, 2026_

::: info Archived roadmap
This roadmap records plans at its publication date and is not a promise of current work. Use the [current documentation](/general/quickstart) and the [repository](https://github.com/ahmad9059/HyprFlux) for present behavior.
:::

The first release of HyprFlux was only the starting point.

Now that the project is public, the next phase is about refinement. The goal is not to add features for their own sake, but to improve the overall experience while keeping HyprFlux focused.

## Priorities at the time

The next updates were expected to focus on:

- improving installer clarity and reliability
- expanding documentation for customization
- refining theme consistency across components
- making the configuration modules easier to understand
- polishing the small workflow details that matter every day.

## Documentation as part of the product

The docs are part of the product. They should help new users get started quickly. They should also help existing users understand how the setup is structured, and how to change it without breaking the design. That means future work keeps improving both the desktop and the writing around it.

## Building in public

Publishing updates like this is part of the process. It creates a record of how HyprFlux grows and makes it easier to follow the direction of the project over time.
